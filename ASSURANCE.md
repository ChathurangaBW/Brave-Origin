## Backup-always guarantee

The tool never writes the live file without a backup first.

- **Patch:** before writing, it saves `Local State.bak.<timestamp>` next to the
  live file. Proven in every patch step (e.g. `Local State.bak.20260101-000000`).
- **Restore:** `--restore` also backs up the current target before overwriting
  (the transcript shows a `…_2` backup being made), then copies the backup
  bytes back. Proven byte-exact: restored hash equals the original hash.
- **Scan:** read-only. The proof asserts hash + mtime unchanged and no new
  `.bak` after a scan (`BASELINE zero-write: PASS`), including on the real
  user profile.

## Honest boundary (future Brave scheme changes)

This is where the tool deliberately stops.

- **Detect + fail closed on classification.** If Brave later renames or reshapes
  its markers, the tool does **not** guess. It reports `BROKEN` (needs repair)
  rather than `OK`, so a future scheme is never mistaken for a healthy one.
  R6 proves this on a deliberately unknown shape.
- **Never corrupt on scan.** Scan writes nothing, even against an unknown
  shape — verified byte-identical before/after.
- **Non-destructive apply.** On an unknown shape, apply adds only the known
  keys and keeps the vendor's unknown keys; the result is still valid JSON.
- **What is *not* claimed.** The tool cannot guarantee that a future Brave
  build will honour the repaired shape, and it does not attempt to reinterpret
  a genuinely new scheme. The payload is a community-bypass shape, not
  vendor-verified licensing. When the shape changes beyond recognition, the
  correct outcome is "Needs repair" and a human decision — not a silent success.

## If you see an unknown state

1. Click **Scan** (it is read-only and safe).
2. If the result looks wrong for your Brave build — e.g. it says `BROKEN` on a
   file you believe is healthy, or `OK` when it clearly is not — do **not**
   patch. Copy the full Scan output.
3. Open an issue and paste the Scan output together with your Brave Origin
   version and channel. Do not paste secrets from `Local State`.
